# 📊 نظام قيد المحاسبي المتكامل (Qoyod Accounting ERP)

نظام محاسبي وإداري سحابي متكامل ومصمم بأسلوب عصري وأنيق (ستايل جاذرن النظيف الفاخر باللونين الأبيض والبنفسجي) مخصص لإدارة وتوحيد الحسابات المالية لـ **5 كيانات واستثمارات مختلفة** تحت حساب مالك موحد:

1. 🏢 **شركة المحاماة والاستشارات القانونية** (محاسبة بالقضية والعقد والأتعاب).
2. 🍔 **مطعم الوجبات السريعة** (إيرادات الصالة وطلبات التوصيل ومصروفات المواد الغذائية).
3. 🌾 **مزرعة الإنتاج الزراعي** (مبيعات المحاصيل والتمور والأسمدة والمواشي).
4. ✂️ **صالون الحلاقة والعناية الرجالية** (إيرادات الخدمات ومستلزمات الصالون).
5. 🏠 **البيت والمصروفات الشخصية** (إدارة المعيشة والالتزامات الأسرية المعزولة مالياً).

---

## 💎 المميزات الرئيسية للأنظمة والوظائف:

- 🧾 **الفوترة الإلكترونية المتوافقة مع هيئة الزكاة والضريبة والجمارك (ZATCA):**
  - إصدار فواتير ضريبية مبسطة معتمدة.
  - توليد رمز الاستجابة السريعة القياسي **(ZATCA QR Code TLV)** لحظياً.
  - قالب طباعة فواتير أنيق ومتوافق مع مقاسات A4 والإيصالات الحرارية.
- 📦 **إدارة المخزون والمستودعات:**
  - تتبع دقيق للأصناف بكود الـ SKU وسعر التكلفة وسعر البيع.
  - تنبيهات فورية للنواقص وحد إعادة الطلب.
  - إمكانية التعديل والجرد الميداني السريع.
- 🛍️ **المشتريات وفواتير الموردين:**
  - تسجيل أوامر الشراء وفواتير الموردين بالآجل أو نقداً وبنكياً.
  - احتساب تلقائي لضريبة المدخلات (15%).
- 🏦 **الخزينة وحركات البنوك:**
  - إدارة أرصدة الصندوق النقدي (كاش)، ومصرف الراجحي، والبنك الأهلي التجاري.
  - سندات قبض وإيداع وسندات صرف وتغذية فورية.
  - إمكانية تحديد وتعديل الأرصدة الافتتاحية الحقيقية لبدء النشاط.
- ⚖️ **دفتر اليومية العامة والقيود المزدوجة:**
  - ترحيل آلي متزن لكافة القيود المحاسبية الناتجة عن الفواتير والسندات والمشتريات.
  - إمكانية إضافة قيود تسوية يدوية مع التحقق من توازن طرفي القيد (مدين = دائن).
- 📈 **التقارير المالية وقائمة الدخل والأرباح:**
  - قائمة الدخل والأرباح والخسائر المجمعة والمفصلة لكل نشاط.
  - ملخص إقرار ضريبة القيمة المضافة (VAT 15%) وتحديد صافي الضريبة المستحقة للهيئة.
  - رسوم بيانية تفاعلية (Chart.js) تتابع الأداء وتوزيع الإيرادات لحظياً.
- 💾 **قاعدة بيانات وحفظ دائم:**
  - حفظ دائم في القرص داخل ملف `web/data.json` مدعوماً بخادم Node.js مع مزامنة محلية.
  - إمكانية تصدير نسخة احتياطية بصيغة JSON بنقرة واحدة.

## 🚀 طريقة التشغيل والبدء السريع:

### المتطلبات:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 16 أو أعلى).

### خطوات التشغيل:
```bash
# 1. الدخول لمجلد المشروع
cd "نظام المحاسبي"

# 2. تشغيل الخادم
npm start
```
أو من داخل مجلد `web`:
```bash
cd web
node server.js
```

افتح المتصفح وتوجه إلى:
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🎨 التقنيات المستخدمة:
- **Frontend:** Vanilla HTML5, Tailwind CSS, Cairo Google Font, Chart.js, QRCode.js
- **Backend:** Node.js HTTP Server, REST APIs (`/api/state`)
- **Storage:** JSON Flat File Database (`data.json`) + LocalStorage Fallback Dual Sync
